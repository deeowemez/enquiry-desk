Meridian Enquiry Desk

An automated first reply for a tutoring company's enquiry inbox. It answers questions about the business (subjects, prices, how booking works, policies) only from a table of facts, checks every price and link in its own reply before a person sees it, and sends anything risky or personal to a member of staff.

This is a portfolio demo. Meridian Tutors is a fictional company: every price, policy and enquiry is invented, and the connected mailbox is a test inbox that receives only test messages. It is not a public service and does not accept enquiries from the public.

What it does with the mailbox

  • Reads new messages in the test inbox, so each one can be classified and answered.
  • Saves a suggested reply as a draft in the same mailbox for a person to review. It does not send email on its own.
