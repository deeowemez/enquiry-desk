Privacy Policy

Meridian Enquiry Desk · last updated 30 October 2026

The Meridian Enquiry Desk is a portfolio demo, not a public service. Meridian Tutors is a fictional company. The app is connected to one test mailbox owned by the developer, and only test messages with invented content are sent to it. No one else signs in to the app.

What the app accesses

With the mailbox owner's permission, through Google's Gmail API, the app:

  • reads new messages in the test inbox (sender, subject, body and message id);
  • creates draft replies in the same mailbox. It never sends email by itself: a person reviews each draft.

How the data is used

  • Message text is sent to Amazon Bedrock (AWS) to classify the enquiry and draft a reply. Bedrock does not use this data to train models.
  • Each enquiry, its classification and the draft reply are stored in a database on the developer's own server, to show the workflow and measure its accuracy.
  • Staff alerts (Telegram) carry only a link to a private review page, never the message content.

The data is not sold, shared with anyone else, or used for advertising.

Google user data

The app's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Keeping and deleting data

Test enquiries are kept in the demo database for as long as the demo runs. Access can be revoked at any time from the Google account's third-party access settings, and stored data is deleted on request.

Contact

Questions about this policy: open an issue on the project's GitHub page.
